# SceNoCo Game

A skill for making or changing a browser game with [SceNoCo](https://github.com/RomaRogov/scenoco-three): three.js scenes written in TSX, with no React, and Unity-style behaviours, from the `@scenoco-three` npm packages.

It gives an agent the whole workflow: read the rules card, write the game, run `npm run check`, then play it in a real browser through `window.__scenoco` until each phase is proven.

The skill is instructions only. It runs nothing by itself and needs no account or API key. The game it writes installs SceNoCo and three.js from npm, in your project.

This repository is published from [`skills/scenoco-game`](https://github.com/RomaRogov/scenoco-three/tree/main/skills/scenoco-game) in the SceNoCo repository, so changes go there.
